A responsive glassmorphism login screen recreated from the uploaded 28-second screen recording.

## Visible design and interactions
- Purple/pink gradient background with a translucent glass login panel
- Small animated avatar with blinking eyes
- Account Login heading
- Email Address and Password fields
- Password show/hide control
- Remember Me checkbox and Forgot Password action
- Gradient Sign In button
- Welcome Back success state

## Run
Open `index.html` directly in a modern browser, or open the folder in VS Code and use Live Server. No dependencies or build step are required.

## Important authentication note
This is a front-end UI demo. The form validates email format and a minimum six-character password, then shows the success state. It does **not** authenticate a real account, store credentials, or send a password-reset email. Connect your backend/auth provider before production use.

## Source extraction note
The recording shows code in a small editor area, but the source text is not legible enough to transcribe reliably at the supplied video resolution. This project recreates the visible UI and behavior; it should not be treated as the exact original source code.
